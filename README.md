# Games Programming

This repository contains two games:

## Road Hopper 3D

A browser-based 3D game built with JavaScript, Three.js, WebGL, and Vite. Guide a cat across the road while avoiding rats. Use the arrow keys to move, Space or P to pause, and R to restart.

To run, open `WebGL_and_ThreeJS_roadhopper`, then run `npm install` and `npm run dev`.

## 2D Platformer

A 2D platform game built with Unity 6000.6.9f1 and C#. Move with A/D or the arrow keys, and jump with Space, W, or Up. The project uses Unity's Input System, Rigidbody2D, Animator, and TextMesh Pro for movement, animation, and UI.

Open `Unity/UnityGame1` in Unity and load `Assets/Scenes/SampleScene.unity`. The Pixel Adventure 1 sprites must be installed locally from the Unity Asset Store; they are not included in the repository.
